## Goal
Implement a comprehensive suite of browser-based tests to verify mood-based filtering, non-repeating shuffle logic, and UI updates, ensuring the application meets the specified functional requirements.

## Acceptance criteria

- [ ] Add unit tests for filtering logic (in `test/logic.test.js` or similar)
- [ ] Add unit tests for shuffling logic (in `test/logic.test.js` or similar)
- [ ] Add browser/UX tests (in `test/ux.test.js`) to verify that clicking a mood button updates the UI
- [ ] Ensure all tests pass when running `node --test`

## Out of scope

- Refactoring the entire application codebase (unless specifically needed to make it testable)
- Adding new features

## Constraints

- Use the built-in `node --test` runner
- Keep pure logic in `logic.js` (or similar, per project rules) for easy testing
- Tests must be runnable locally without external dependencies
