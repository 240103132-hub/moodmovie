## Goal
Implement a minimal, calm UI for the Mood Movie Picker that displays an introduction and provides interactive buttons for the 5 moods.

## Acceptance criteria

- [ ] UI is implemented in `index.html` and `style.css`
- [ ] A short "about" line is displayed explaining the tool
- [ ] 5 buttons for the moods (Cozy, Thrilled, Laugh, Wistful, Inspired) are visible and styled
- [ ] An empty container for the movie card is present for dynamic injection

## Out of scope

- Actual functionality of the buttons (handled in task #4)
- Movie data loading (handled in task #4)

## Constraints

- Use only `index.html` and `style.css`
- Follow a "minimal, calm" design aesthetic
- No frameworks or external UI libraries
