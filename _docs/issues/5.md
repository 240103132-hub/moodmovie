# 5. Shuffling and "Show Another" Logic

## Goal

Implement core browsing behavior: Users can browse movies for a selected mood with shuffling and "show another" functionality without immediate repetition.

## Acceptance criteria

- [ ] User can click a "Show Another" button to see a different movie from the selected mood.
- [ ] Movies do not repeat in a session until all movies for that mood have been shown.
- [ ] When all movies for a mood have been shown, the sequence restarts.
- [ ] Logic for filtering and shuffling is implemented in `logic.js`.
- [ ] Tests exist in `test/logic.test.js` to cover the shuffling and "no-repeat" logic.

## Out of scope

- UI styling improvements (tracked in #7)
- Movie dataset expansion (tracked in #8)

## Constraints

- Keep pure logic in `logic.js`.
- No new dependencies.
- Adhere to vanilla JavaScript.
